# Алексей Антонов Бусти

Статический сайт для GitHub Pages.

## Файлы
- `index.html` — основная SEO-страница
- `materials.html` — тематическая страница
- `faq.html` — FAQ
- `telegram.html` — страница перехода
- `404.html` — обработчик 404
- `robots.txt`
- `sitemap.xml`
- `favicon.svg`

## Публикация
Загрузите все файлы в корень репозитория и включите GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

После публикации добавьте сайт в Яндекс Вебмастер и укажите `sitemap.xml`.
